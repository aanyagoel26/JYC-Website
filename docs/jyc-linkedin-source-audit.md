## LinkedIn image handling

The site should not hotlink or copy LinkedIn CDN images simply because they are publicly visible. LinkedIn images are useful for:
1. confirming event identity and visual direction;
2. identifying event posters and subjects;
3. finding the authoritative post for attribution;
4. deciding which official/permissioned asset should be requested or sourced locally.

For public gallery publication, prefer:
- JYC-owned media;
- event-owned official-site media;
- assets supplied for publication;
- assets with explicit permission;
- locally committed optimized copies with provenance metadata.

Every approved visual should retain event, campus, source URL, capture date and rights/provenance information.
