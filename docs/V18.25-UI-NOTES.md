# V18.25 UI notes

V18.25 selectively uses ideas that are common in open-source React UI work: orbital navigation, restrained reveal/motion, persistent theme tokens and command-palette-style search. The implementation remains local CSS/React rather than adding a large animation dependency or making JYC look like a component showcase.

The visual direction was checked against:

- React Bits component index and creative tools for orbit, reveal, navigation and background patterns.
- Lightweight open-source theme-switch patterns based on CSS custom properties.
- Editorial React design-system examples that treat light/dark mode as a full token system rather than a single background swap.

The JYC palette remains the source of truth: paper/cream light surfaces, near-black night surfaces, JYC red for attention and warm gold for structure.
