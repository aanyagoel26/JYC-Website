# Club member portrait assets

This directory contains the optimized WebP portraits referenced by `src/jyc-club-member-roster.js`.

The matching asset bundle is `jyc-club-member-portraits.zip` supplied with this PR handoff. Extract its `public/assets/club-members/` directory here so all `/assets/club-members/*.webp` paths resolve.

Portraits are ordered and named by the roster mapping. Do not rename files without updating the corresponding `photo` path in the roster.
