# JYC club portraits

Canonical destination for the 40 supplied 2026–27 club-member portraits.

- `portrait-01.webp` through `portrait-20.webp` preserve the first 20 uploads as numbered portraits because no person-to-file mapping was supplied for that set.
- The 20 named WebP filenames correspond to the second set of club-member assignments in `mapping.csv`.
- `mapping.csv` records the original upload order and intended repository filename.
- Club-member cards have an accessible initials fallback. If a portrait binary is absent or fails to load, the initials remain visible instead of a broken-image icon.

Do not infer or assign a person's name to a numbered portrait without an explicit mapping. The actual WebP files must be present in this directory for the photo cards to display them.
