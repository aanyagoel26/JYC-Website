# JYC club portraits

The complete optimized portrait bundle contains 40 WebP images in `public/assets/people/`.

- The 20 named files correspond to the second set of club-member assignments.
- `portrait-01.webp` through `portrait-20.webp` are retained as numbered portraits until their exact names are confirmed.
- The club roster source references the 20 named files under `/assets/people/`.

See `mapping.csv` for upload-order and source-file mapping.

Note: this documentation and the roster path correction are committed separately from the binary image payload. The 40 WebP files themselves still need to be added to this repository.
