# JIIT Youth Club 128 — Official Web Platform

The official production web platform for **JIIT Youth Club (JYC), JIIT Wish Town Campus, Sector 128, Noida**.

> **Notice: Closed Repository.** This repository is maintained exclusively by the authorized JYC 128 technical team. External contributions and pull requests are not accepted.

---

## 🏛️ Platform Overview

JYC 128 is the central coordinating body for major campus events, cultural fests, technical summits, and inter-society initiatives at JIIT Sector 128. This platform provides an immersive, high-performance web experience encompassing:

- **Ecosystem & Hubs:** Comprehensive directory of all 23+ student societies, technical hubs, cultural wings, and creative cells.
- **Events & Fests:** Official flagships including Converge, Ebullience, CyberSrishti, JAI Summit & Hackathon, Dron-O-War, Robospark, Bitbox, and Kshitij.
- **Visual Memory & Media:** High-resolution verified photography archives with responsive AVIF/WebP image pipelines.
- **Leadership & Governance:** Complete faculty advisory and student council profiles with verified campus associations.
- **Announcements & Calendar:** Synchronized campus activity updates and integrated schedule views.

---

## ⚡ Core Architecture

- **Frontend:** React 19, Vite, React Router
- **Interactive Experience:** Modern WebGL canvas, reactive particle motion, 3D tilt interactions, and glassmorphic micro-animations
- **Backend & Data:** Supabase Cloud, Row Level Security (RLS), Edge Functions, CDN asset optimization
- **Quality & Performance:** Automated route shell pre-rendering, PWA offline caching, and strict semantic accessibility (WCAG 2.2 AA)
