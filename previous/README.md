# Previous JYC Website

This folder is the preservation area for the pre-rebuild website.

## Preservation rule
The existing application is kept intact on the `main` branch and at the parent commit of `rebuild/v1-editorial-from-reference`. Do not delete or overwrite its routes, CMS/Supabase integration, event data, club data, media, SEO, admin, or release tooling while rebuilding the public UI.

## Current rebuild direction
Rebuild the public experience from the supplied screenshot and V1 brief:
- dark editorial canvas, warm ivory typography, restrained red accent
- oversized stacked “THE VOICE. THE TALENT. THE SPIRIT.” hero
- JYC 128 identity and campus label
- large authentic event/community photography
- clear navigation and event/clubs/get-involved actions
- responsive layout, readable contrast, no accidental overlays or clipping

## Keep for future use
Preserve existing working routes and data-driven features: Home, About JYC, Leadership, Events, Event Details, Clubs and club details, Gallery, Achievements, Announcements, Join JYC (Coming Soon), Contact, calendar links, verified social channels, recruitment status, content management, accessibility/reduced motion, security, sitemap/SEO, service worker and QA scripts.

The rebuild should replace the public presentation layer, not throw away the underlying product.
